# עוזר תזונה וכושר מבוסס AI

אפליקציית פולסטאק (React + Node.js + MongoDB + Google OAuth 2.0 + Gemini
AI)

## סקירה כללית

הפרויקט מספק ניתוחים תזונתיים וכושר מותאמים אישית בעזרת שילוב של: -
חישובים מדויקים בצד השרת (BMR, TDEE, חלבון יומי) - בדיקת התאמה בין אחוזי
שומן והמטרה - דוחות AI המבוססים על Gemini של גוגל - מערכת התחברות מלאה
עם Google OAuth 2.0 - ממשק משתמש מסודר וברור באמצעות React

המערכת מבטיחה בטיחות, עקביות ודיוק על‑ידי שילוב בין לוגיקה דטרמיניסטית
לבין ניתוח AI.

# תכונות מרכזיות

## 1. התחברות OAuth 2.0 עם גוגל

- התחברות מלאה באמצעות גוגל
- יצירת JWT בשרת
- שמירת משתמשים חדשים במונגו
- AuthContext לניהול סטייט גלובלי
- שליחת טוקן לכל בקשות ה‑API

---

## 2. יצירת פרופיל משתמש

המשתמש מזין: - גיל, גובה, משקל, מין\

- אחוז שומן\
- רמת פעילות\
- העדפות תזונה\
- מטרה: בריאות כללית / חיטוב / מסה\
- מאכלים אהובים

הנתונים עוברים ולידציה בשרת ובקליינט.

---

## 3. חישובים בצד השרת

### BMR

מבוסס נוסחת Mifflin--St Jeor.

### TDEE

מחושב בעזרת activity factor.

### חלבון יומי

- בריאות כללית: משקל × ‎1.6\
- חיטוב: משקל × ‎2.2\
- מסה: משקל × ‎2.0

### יעד קלוריות

תחזוקה / חיטוב / מסה.

---

## 4. מערכת המלצות לפי אחוז שומן

בדיקה אם המטרה מתאימה למצב הגוף.

### גבר

- מתחת ל‑7% = חיטוב לא מומלץ\
- מעל 22% = מסה לא מומלצת

### אישה

- מתחת ל‑14% = חיטוב לא מומלץ\
- מעל 35% = מסה לא מומלצת

הפונקציה מחזירה:

    { isRecommended, level, message }

---

## 5. דו"ח מקדים (Pre‑Report)

לפני דוח ה‑AI: - אם המשתמש באזור סכנה → מחזירים רק אזהרה\

- אחרת → מחזירים מסר ברור על חלבון וקלוריות

מונע מה‑AI סתירות וטעויות.

---

## 6. שכבת בטיחות ל‑AI (Pre‑Prompt Safety Layer)

ה‑AI מחויב להשתמש ב: - BMR/TDEE מהשרת\

- חלבון וקלוריות כפי שחושבו\
- דגלי dangerZone

מונע המלצות קיצוניות או חישוב מחדש.

---

## 7. ממשק משתמש React

- טופס פרופיל עם Formik\
- Input גנרי (checkbox/select/textarea/text)\
- קומפוננטת Profile להצגת נתוני המשתמש\
- קומפוננטת AIReport להצגת הדוח\
- ניהול סטייטים: loading / success / error\
- useTransition ל‑UX חלק
